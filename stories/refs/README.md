# Reference frames

`garden-of-teeth/` holds two frames taken from this rig's own render of "Thorns and Static" (shots 8 and 22), used as
look references for "The Garden of Teeth". They are AI-generated (LTX-2.5).

Some project files (`19-liminal-clowns.txt`, `20-warm.txt`, `00-place-smoke.txt`) name reference photos of places
that were not made by the rig; those photos are not in this repository. Add your own images at the same paths to
re-render those projects, or drop the `[place=...]` token.
